# EcoCity — Платформа коллективного экологического мониторинга города

MVP-сервис для проведения опросов, сбора обратной связи по экологической обстановке и автоматического обнаружения инцидентов на основе IoT-данных и жалоб жителей с привязкой к Яндекс Картам.

## 🚀 Функционал и Ключевые решения
1. **Комплексный индекс района (ECI):** Расчёт составного индекса качества среды на основе 4 компонентов: воздух (`AirScore`), вода (`WaterScore`), жалобы жителей (`CitizenScore`) и динамика изменений (`TrendScore`). Бэкенд автоматически отдаёт `color_hex` для покраски полигонов.
2. **Интеграция с Яндекс Картами:** Отображение подкрашенных полигонов районов города, маркеров датчиков и точек обратной связи (жалоб) в реальном времени.
3. **Автообнаружение инцидентов (Rule-based):** Алгоритм, который автоматически триггерит критическое событие при одновременной фиксации аномалии датчиком и поступлении 3+ жалоб в радиусе 1 км за последний час.
4. **Конструктор опросов:** Инструмент для авторов (экологов/администрации) по созданию и анализу анкет с поддержкой одиночного/множественного выбора и текстовых ответов.
5. **Ролевая модель:** Разделение прав доступа на Гостя, Жителя, Автора опросов и Оператора (Админа).

## 🛠️ Технологический стек
- **Backend:** FastAPI, SQLAlchemy 2.0 (Async), Alembic, Asyncpg, Pydantic v2, PostgreSQL + PostGIS (GeoAlchemy2)
- **Frontend:** React, TypeScript, Vite, Yandex Maps API

## 📂 Структура проекта
- `backend/app/models/` — доменно-разделенная структура сущностей (core, users, sensors, feedback, incidents, surveys) без циклических импортов.
- `backend/alembic/` — асинхронная среда миграций базы данных с поддержкой PostGIS ГИС-типов.
- `backend/database/` — SQL-скрипты для инициализации пространственного расширения и сидирования демо-данных.
- `simulator/` — асинхронный симулятор IoT-датчиков для демонстрации аномалий (выбросы PM2.5, загрязнение воды).

## 💻 Быстрый запуск (Разработка)

### Бэкенд
1. Перейдите в папку бэкенда:
   ```bash
   cd backend
   ```
2. Активируйте виртуальное окружение и установите зависимости:
   ```bash
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Настройте конфигурацию в локальном файле `.env` по шаблону `.env.example`.
4. Инициализируйте PostGIS в вашей СУБД и примените миграции:
   ```bash
   alembic upgrade head
   ```
5. Запустите сервер:
   ```bash
   uvicorn app.main:app --reload
   ```
